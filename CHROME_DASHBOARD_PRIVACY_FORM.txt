1. SINGLE PURPOSE
--------------------------------------------------------------------------------

[Single purpose description] (Limit: 1,000 characters | Current: 271 chars)
--------------------------------------------------------------------------------
StackVibe has a single, focused purpose: to inspect web pages on demand to identify frontend technology stacks (frameworks, CMS, analytics, CDN infrastructure) and extract computed CSS design tokens, DOM component geometry, and AI prompts for web developers and UI/UX designers.


--------------------------------------------------------------------------------
2. PERMISSION JUSTIFICATION
--------------------------------------------------------------------------------

[activeTab justification] (Limit: 1,000 characters | Current: 282 chars)
--------------------------------------------------------------------------------
The activeTab permission is required to access the URL, title, and DOM structure of the currently focused browser tab only when the user explicitly clicks the StackVibe extension icon or opens the developer inspection console. StackVibe never accesses tabs automatically without user initiation.


[scripting justification] (Limit: 1,000 characters | Current: 272 chars)
--------------------------------------------------------------------------------
The scripting permission is required to execute read-only content script inspectors (content/design_extractor.js and content/main_world_detector.js) that inspect global window variables and compute element geometry in the context of the active web page requested by the user.


[storage justification] (Limit: 1,000 characters | Current: 213 chars)
--------------------------------------------------------------------------------
The storage permission is required to store user settings, scan history, saved site snapshots ("Snap Library"), and custom inspiration links locally in the user's browser using chrome.storage.local.


[Host permission justification] (Limit: 1,000 characters | Current: 295 chars)
--------------------------------------------------------------------------------
Host permissions for <all_urls> are required to allow StackVibe's read-only inspection script to analyze technology signatures and computed CSS styles on web pages across any domain that the user explicitly chooses to inspect. The inspector performs no background network requests or tracking.
