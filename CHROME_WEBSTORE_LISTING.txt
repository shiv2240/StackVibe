2. DETAILED DESCRIPTION (Chrome Web Store Store Page)
--------------------------------------------------------------------------------

StackVibe is the ultimate evidence-first Developer Web Intelligence Console & Design Spec Extractor. Built for frontend engineers, UI/UX designers, and AI developers, StackVibe inspects any website to instantly identify its full technology stack, extract computed CSS design tokens, compute DOM component geometry, and generate zero-hallucination AI prompts for Claude, GPT-4o, Gemini, Cursor, Lovable, and Manus.

Why Install StackVibe?
Most web detectors check a single CSS class or window object, leading to false positives on minified production sites. Design extractors often fabricate generic HEX colors (#4F46E5) and tell AI to "make a modern UI". StackVibe is different: it operates as a multi-layer evidence graph that inspects DOM Fibers, runtime globals, script bundles, stylesheets, and response headers—never guessing or inventing false fallback values.

===================================
KEY FEATURES & CAPABILITIES
===================================

1. High-Precision Tech Stack Fingerprinting:
- Detects 30+ frameworks, libraries, CMS, and cloud tools including React, Next.js, Vue.js, Nuxt 3, Angular, Svelte/SvelteKit, Polymer, Shaka Player, Tailwind CSS, Bootstrap, Material UI, Shopify, WordPress (themes & plugins), Google Analytics/GA4, GTM, Mixpanel, Hotjar, Segment, Vercel, Cloudflare, and Netlify.
- Dual-World Engine: Inspects true MAIN-world runtime objects (window.React, window.__NEXT_DATA__, __reactFiber$) and ISOLATED-world computed DOM styles.
- Shows confidence scores (%) and explicit evidence lines for every technology.

2. Computed Design Forensics (getdesign.md):
- Semantic Color Frequency Mapping: Identifies canvas background, surface cards, button colors, header navbar, and heading typography colors.
- Exact Typography Scale: Extracts computed font families, H1/H2 font sizes, font weights, and line heights.
- Component Geometry Analysis: Computes exact bounding box dimensions (width x height), padding, border radius, and shadow elevation for headers, hero banners, buttons, cards, footers, and interactive forms.
- Full 6-Level DOM Architecture Tree Graph with inline "Copy Tree Graph" buttons.

3. Zero-Hallucination AI Prompts & Static Code Analyzer:
- Generates RECONSTRUCTION MODE prompts for Claude 3.5 Sonnet, GPT-4o, Gemini 1.5 Pro, Cursor, and Lovable.
- Includes a dedicated "Frontend Technology Profiler & Static Code Analyzer" task that outputs a strict 100% accuracy JSON tech stack audit.

4. Design Mixer (Inspiration Lab v2.0):
- Combine design patterns from multiple reference sites (e.g. Hero from Stripe + Nav from Linear + Buttons from Vercel + Cards from Airbnb) into a unified prompt.
- Custom Inspiration Links: Add custom domains/URLs with persistent local storage.
- 6-Criteria Master Directives: Configure Target Stack, Component Scope, Visual Direction, Interactivity Level, Output Format, and Custom Constraints.
- Built-in Pattern Rationale Dictionary & Live UI Synthesis Explanation Cards.

5. Cloud Authentication & Snap Library:
- Real-time cloud sync powered by Convex Backend (https://oceanic-dolphin-290.convex.cloud).
- Save site snapshots and view your personal Snap Library grid rendered with actual extracted brand colors.
